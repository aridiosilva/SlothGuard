## Publishing on DEV
1. Open the Submission Template link on the challenge page; it fills the required tags (devchallenge, hf26challenge).
2. Title: SlothGuard: a lazy access reviewer that asks your phone before it revokes anything
3. Paste post_en_paste.md below the front matter, upload the 8 images and replace each UPLOAD_ name with the DEV image URL.
4. Preview, then publish once. Publish the Portuguese version afterwards, without the challenge tags, and put the URL of the English post in its first line.
